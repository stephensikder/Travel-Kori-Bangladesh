# Travel Kori Bangladesh — RESTful API Specification
**Version:** 2.0 (Production Verified)  
**Base URL (Localhost):** `http://localhost:5000`  
**Protocol:** HTTP/1.1 REST over JSON  
**Authentication Scheme:** Role-Based Session / Request Verification (User ID & Role Verification)

---

## 1. Overview and Standards
The Travel Kori Bangladesh backend is an Express.js REST application operating on Node.js and MongoDB. All endpoints accept and return `application/json` unless serving static assets. Successful operations return `{ success: true, ... }` with standard HTTP status codes (`200 OK`, `201 Created`). Client errors return `{ success: false, message: "..." }` with status `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`, or `404 Not Found`. Server anomalies return `500 Internal Server Error` or `503 Service Unavailable` if database connectivity is disrupted.
